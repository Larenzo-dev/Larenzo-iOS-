# Larenzo iOS

Larenzo is a modern iOS application built with Swift and SwiftUI, monetized with Google AdMob.

## Features
- Clean SwiftUI interface
- AdMob integration (Banner, Interstitial, Rewarded Ads)
- Fast and lightweight performance
- iOS 17+ support

## Tech Stack
- Swift 5, SwiftUI, UIKit
- Xcode, Git
- Google Mobile Ads SDK
- REST APIs

## What I Learned
Building AdMob integration, app architecture, and App Store deployment workflow.
